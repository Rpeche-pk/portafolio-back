Zephyr Cygnus WA

Description

¿Cansado de esperar? 🥱 Nosotros también lo estábamos. Por eso, presentamos nuestro innovador servicio de mensajería Chat Bot en WhatsApp.

📩 Adiós a la espera de la carta: Olvídate de las largas demoras para recibir información importante.
⏳ Respuestas en tiempo récord: ¿Harto de esperar minutos para una respuesta? Nuestro chat bot responde en segundos.

Este proyecto nació inspirado en un lugar muy especial para mí, el Restobar Kraken de la ciudad de Ica. Dicho Chat Bot se encarga en primera instancia de gestionar el proceso de venta de comida rápida. Con el tiempo este Chat Bot se podrá amalgamar a casi cualquier proceso comercial.
