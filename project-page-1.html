Proyecto Tesis Maivibot

Descripción

MaiviBot es un proyecto de tesis: un chatbot con IA generativa y web scraping en Python para buscar inicialmente productos de abarrotes de Tottus, Plaza Vea y Metro en Ica. Redujo el tiempo de consulta y mejoró la precisión de los resultados: se observó una mejora del 77% en la eficiencia de búsqueda y el 69% de los usuarios reportó una experiencia positiva.

BuilderBot, un wrapper con proveedores para WhatsApp, Telegram e Instagram, permitió crear flujos en Node.js, con GPT-4o mini para el agente de IA. Una API REST con Spring Boot y Java 17 servía los datos extraídos desde MongoDB Atlas. Python, Selenium y Selenium Grid permitieron búsquedas en paralelo mediante web scraping, sobre la prueba gratuita de Google Cloud.
